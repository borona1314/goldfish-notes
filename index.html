ซิงค์ข้ามเครื่อง

วางค่า Firebase config (จาก Firebase Console) ที่นี่ — ใช้ config เดียวกันทุกเครื่องที่อยากให้บ่อเดียวกันซิงค์กัน

1. console.firebase.google.com → สร้างโปรเจกต์ใหม่
2. Build → Realtime Database → Create Database
3. ตั้ง Rules ให้อ่าน/เขียนได้ (เฉพาะใช้ส่วนตัว)
4. Project settings → Your apps → เว็บ (</>) → คัดลอก config object
